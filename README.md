## `01` — Sobre o projeto

<a id="sobre"></a>

O **ReStart 50+** é uma plataforma de educação digital inclusiva concebida para apoiar pessoas com 50 anos ou mais no aprendizado de novas tecnologias.

A proposta é oferecer um ambiente de aprendizagem simples e acessível, no qual os usuários possam explorar conteúdos introdutórios, realizar avaliações, acompanhar seu progresso e esclarecer dúvidas durante a jornada de aprendizagem.

Desenvolvida com **Python e Streamlit**, a aplicação reúne recursos educacionais e funcionalidades de acessibilidade em uma única interface, considerando diferentes necessidades e níveis de familiaridade com a tecnologia.

O projeto foi desenvolvido no contexto da **Global Solution 2025.2**, como uma experiência de trabalho em equipe, aplicação prática de conhecimentos e exploração de soluções tecnológicas com propósito social.

## `02` — O desafio

<a id="desafio"></a>

A familiarização com ferramentas digitais pode representar uma barreira para pessoas que não tiveram as mesmas oportunidades de contato com a tecnologia ao longo da vida.

O ReStart 50+ parte dessa necessidade para propor uma experiência educacional que combina conteúdos introdutórios, prática, acompanhamento individual e recursos de acessibilidade.

A solução busca tornar o contato com temas tecnológicos mais compreensível e incentivar a autonomia dos alunos no uso de ferramentas digitais.

## `03` — Funcionalidades

<a id="funcionalidades"></a>

### 🎓 Catálogo de cursos

Organização de conteúdos introdutórios em diferentes áreas da tecnologia e do ambiente digital:

- Inteligência Artificial;
- Alfabetização em Dados;
- Marketing Digital;
- Internet das Coisas (IoT);
- Produtividade e Trabalho Remoto;
- Empreendedorismo Sênior.

Cada curso pode reunir informações sobre o conteúdo, materiais de apoio, avaliações e registro do progresso, conforme a implementação disponível no projeto.

### 📝 Avaliações e quizzes

Atividades para verificar a compreensão dos conteúdos estudados.

- Questões de múltipla escolha;
- Correção automática;
- Registro de tentativas;
- Cálculo de notas;
- Histórico de avaliações.

### 📊 Dashboard do aluno

Área destinada ao acompanhamento da jornada de aprendizagem, com informações como:

- Progresso geral nos cursos;
- Média das notas;
- Histórico das tentativas recentes;
- Percentual de conclusão da trilha formativa.

### 💬 Contato com instrutores

Recurso para encaminhamento de dúvidas diretamente pela plataforma, com registro das mensagens e histórico de contato do aluno.

### 🤖 Chatbot integrado

Assistente para orientar o usuário em dúvidas básicas relacionadas ao funcionamento da plataforma, aos cursos disponíveis e à localização de recursos.

### ♿ Acessibilidade digital

Recursos planejados para proporcionar uma experiência mais confortável e adaptável:

- Aumento e redução do tamanho da fonte;
- Modo de alto contraste;
- Leitura de textos em voz alta pelo navegador;
- Botões de áudio em conteúdos selecionados;
- Interface com cores e espaçamentos voltados à legibilidade.

## `05` — Organização dos dados

<a id="dados"></a>

A aplicação utiliza arquivos JSON locais para armazenar informações de forma simples, de acordo com a estrutura descrita para o projeto.

| Arquivo ou diretório | Finalidade |
|---|---|
| `users.json` | Dados dos usuários e informações relacionadas ao progresso |
| `contacts.json` | Registro de mensagens enviadas pelo formulário de contato |
| `imagens/` | Diretório destinado a recursos de imagem |

O fluxo de autenticação descrito para o MVP utiliza nome e e-mail.

> **Nota de segurança:** o armazenamento local em JSON e a identificação simplificada de usuários são adequados apenas para demonstrações controladas. Uma aplicação em produção precisaria de autenticação robusta, controle de acesso, proteção de dados pessoais, validação de entradas e armazenamento persistente seguro.

## `06` — Como executar o projeto

<a id="execucao"></a>

### Pré-requisitos

- Python 3.10 ou superior;
- Git;
- pip para instalação de pacotes Python.

### 1. Clone o repositório

```bash
git clone https://github.com/Manu11000/Global-Solution---2025.2.git
```

Entre na pasta clonada:

```bash
cd Global-Solution---2025.2
```

### 2. Crie um ambiente virtual

```bash
python -m venv .venv
```

Ative o ambiente virtual.

**Windows — PowerShell:**

```powershell
.venv\Scripts\Activate.ps1
```

**Windows — Prompt de Comando:**

```bat
.venv\Scripts\activate.bat
```

**Linux ou macOS:**

```bash
source .venv/bin/activate
```

### 3. Instale as dependências

```bash
python -m pip install streamlit
```

Caso o projeto tenha um arquivo `requirements.txt`, prefira instalar as dependências listadas nele:

```bash
python -m pip install -r requirements.txt
```

### 4. Execute a aplicação

Se o arquivo principal estiver na raiz do projeto e tiver o nome informado:

```bash
streamlit run ReStart50-Web-MVP.py
```

O Streamlit disponibilizará o endereço local da aplicação no terminal, normalmente `http://localhost:8501`.

> Os comandos pressupõem que os nomes dos arquivos e a estrutura correspondam aos descritos. Confira o repositório caso algum caminho seja diferente.
